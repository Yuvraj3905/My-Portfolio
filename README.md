# Yuvraj Singh | AI & Full Stack Engineer

A high-performance portfolio featuring a **cyberpunk HUD design**, reflecting expertise in **Agentic Workflows**, **Generative AI**, and **Real-time Systems**.

---

## 🚀 Key Features

- **Cyberpunk Aesthetics**: High-contrast dark mode with neon cyan accents, scanline effects, and flicker animations.
- **Agentic Link Loader**: Custom loading sequence simulating an agentic connection.
- **Interactive HUD**: Project cards and skill nodes with hover-glow effects and glassmorphism.
- **Parallax Landscapes**: Dynamic SVG landscapes that respond to scroll progress.
- **Typewriter Terminal**: Interactive terminal-style bio with simulated real-time input.

## 🛠 Tech Stack

- **Framework**: [React.js](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Inter & Outset (System UI Fallbacks)

## 📂 Project Highlights

- **Self-Healing RPA Engine**: Autonomous scraper with multi-modal feedback loops.
- **PhygitalMax Backend**: Sub-300ms latency synchronization for livestream commerce.
- **Talk-to-Data SaaS**: Secure RAG-based natural language SQL query engine.
- **HomeSeeker**: IoT AI security device for real-time threat detection.

## 🚦 Getting Started

### Prerequisites

- Node.js (v18+)
- npm / yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Yuvraj3905/My-Portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run development server:
   ```bash
   npm run dev
   ```
